# PWA ลงชื่อเข้าใช้ห้องคอมพิวเตอร์

ชุดไฟล์ในโฟลเดอร์นี้พร้อมนำไปเผยแพร่เป็นเว็บแอป PWA บน Netlify และติดตั้งจาก Microsoft Edge บน Windows ได้ โดยไม่ต้องสร้างไฟล์ EXE

## ไฟล์สำหรับอัปโหลด

อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์ `outputs` ไปยังโฟลเดอร์เผยแพร่ของ Netlify (ต้องมี `index.html` อยู่ที่หน้าแรก):

- `index.html` หน้าลงชื่อและโค้ดกรองรายชื่อ
- `config.js` ลิงก์ CSV รายชื่อนักเรียนและตำแหน่งคอลัมน์
- `manifest.webmanifest`, `sw.js`, `icon.svg` สำหรับติดตั้งเป็น PWA และเปิดหน้าเว็บที่เคยโหลดไว้
- `netlify.toml` และ `netlify/functions/roster.mjs` สำหรับดึง CSV ผ่าน Netlify Function เพื่อเลี่ยงข้อจำกัด CORS

ไม่จำเป็นต้องอัปโหลดไฟล์ `main.js`, `preload.js`, `package.json` สำหรับ PWA

## เผยแพร่บน Netlify

1. เปิด Netlify แล้วเลือกเพิ่มเว็บไซต์แบบ manual deploy หรือเข้าเว็บไซต์เดิมของโรงเรียน
2. เนื่องจากแอปใช้ Netlify Function แก้ CORS ต้องเชื่อม Netlify กับ Git repository แล้วตั้ง Base directory เป็น `outputs`, Publish directory เป็น `.`, Functions directory เป็น `netlify/functions` จากนั้น deploy (หรือใช้ Netlify CLI โดย `cd outputs` แล้วสั่ง `netlify deploy --prod --dir .`) การลากไฟล์เว็บแบบ manual deploy จะไม่รัน Function
3. เปิด URL ของเว็บ Netlify ที่ได้ด้วย Edge ตรวจว่าหน้าลงชื่อแสดงขึ้น
4. ทดสอบเลือกชั้น แล้วตรวจว่ารายชื่อนักเรียนของชั้นนั้นปรากฏ จากนั้นส่งรายการทดสอบและตรวจผลใน Google Forms/ชีตคำตอบ

## ติดตั้งบน Windows

ทำบนคอมพิวเตอร์แต่ละเครื่อง (รวม 10 เครื่อง):

1. เปิด URL เว็บ Netlify ด้วย Microsoft Edge
2. เลือกเมนู `…` มุมขวาบน > **Apps** > **Install this site as an app** (บางรุ่นอาจแสดงปุ่มติดตั้งที่แถบที่อยู่)
3. เปิดแอปจาก Start แล้วคลิกขวาไอคอนบนแถบงานเพื่อปักหมุด หากต้องการ
4. ตั้งให้เปิดอัตโนมัติ: กด `Win + R`, พิมพ์ `shell:startup`, กด Enter แล้ววาง shortcut ของแอปที่ติดตั้งไว้ในโฟลเดอร์ที่เปิดขึ้น ทำซ้ำในบัญชี Windows ที่นักเรียนใช้

PWA ต้องเผยแพร่ผ่าน HTTPS (Netlify ให้ HTTPS) เพื่อใช้ service worker และติดตั้งได้ การแคชช่วยเปิดหน้าเดิมเมื่อเน็ตขัดข้อง แต่รายชื่อและการส่งแบบฟอร์มยังต้องใช้อินเทอร์เน็ต

## รายชื่อนักเรียนจาก Google Sheets

`config.js` เรียก `/.netlify/functions/roster` ซึ่งดึง CSV ที่เผยแพร่จาก Google Sheets ผ่าน Netlify Function เพื่อเลี่ยง CORS ของเบราว์เซอร์ โดยให้คอลัมน์แรกเป็นชั้นและคอลัมน์ที่สองเป็นชื่อนักเรียน (`gradeColumn: 0`, `nameColumn: 1`) แอปจะกรองชื่อหลังจากเลือกระดับชั้น และโหลดรายชื่อใหม่ทุก 15 นาที

สำคัญ: ต้อง deploy ด้วย Netlify CLI หรือเชื่อม Git repository โดยกำหนด publish directory เป็นโฟลเดอร์นี้ เพื่อให้ Netlify ประมวลผล `netlify/functions/roster.mjs` ด้วยการลากไฟล์ HTML ขึ้นแบบ manual deploy จะไม่ติดตั้ง Function และจะแสดงข้อผิดพลาด

โค้ดคงปลายทาง Google Forms และรหัสช่องเดิม: คำนำหน้า `entry.1226252401`, ชื่อ `entry.1405412445`, ระดับชั้น `entry.193315918`, วิชา `entry.994538917`, หมายเลขเครื่อง `entry.1056822339`.

ลิงก์ CSV ที่เผยแพร่ทำให้ผู้ที่มีลิงก์อ่านรายชื่อได้ โปรดตรวจว่าโรงเรียนอนุญาตวิธีนี้ก่อนแจก URL หากไม่อนุญาต ควรใช้บริการหลังบ้านที่จำกัดสิทธิ์แทน

## หากแอปไม่อัปเดตหลัง Deploy

ปิดแอปแล้วเปิดใหม่ หากยังเห็นหน้าเก่า ให้เปิดเว็บด้วย Edge แล้วกด `Ctrl + Shift + R` หรือถอนการติดตั้ง PWA และติดตั้งใหม่ Service worker จะรับไฟล์หน้าเว็บล่าสุดเมื่อออนไลน์

## หมายเหตุการส่งข้อมูล

Google Forms รับข้อมูลผ่านปลายทางเดิมใน iframe ซ่อนอยู่ หน้าจอแสดงข้อความหลังส่งคำขอ แต่เว็บไม่สามารถตรวจยืนยันผลตอบกลับจาก Google ได้โดยตรง ให้ตรวจรายการทดสอบในชีตคำตอบก่อนใช้งานจริง
